它是什么

不是新的笔记软件，是挂在备忘录旁边的辅助工具。你不换地方、不导数据、不同步两套东西—— 照常打开备忘录写字，只是能敲 Markdown。

它是 ProNotes 的替代品。ProNotes 已经停止维护， 在 macOS 27 上因为它把备忘录的菜单标题按系统版本硬编码了、而 Apple 改了菜单名而失效。 sugarnote 改成运行时现学菜单结构，不再依赖版本表。

不注入、不修改备忘录

靠系统辅助功能读光标位置，识别到语法后触发备忘录自己的格式化菜单。备忘录本体没被动过。

不记录按键

订阅的是「正文变了」这个通知，不是键盘事件。看不到你按了什么键。

不联网

没有网络请求，没有账号，没有遥测。所有判断都在本机完成。

兼容输入法

从文本状态判断而不是从按键判断，所以用中文输入法拼字时不会误触发。

行内语法敲完闭合的那一半就自动转换。想撤销按 ⌘Z——一次就能退回 Markdown 原文。

行首的 - 和 1. 这类列表标记不用 sugarnote 处理，备忘录自带的智能列表本来就会转。 分隔线推荐写 *** 或 ___：--- 会被备忘录的智能破折号变成破折号。

安装

  1. 从 Releases 下载 DMG， 把 sugarnote.app 拖进「应用程序」。
    一定要先拖进去再运行。直接从 DMG 里双击的话，macOS 会把它放到一个随机只读路径执行，功能会不正常。
  2. 双击打开一次——会被系统拦下，这是正常的。然后放行：
    图形界面：打开「系统设置 > 隐私与安全性」，往下滚到「安全性」一节， 点「已阻止使用 sugarnote.app」右边的仍要打开。

    或者终端一条命令： xattr -d com.apple.quarantine /Applications/sugarnote.app 这个 App 没有付费开发者账号签名、也没公证，所以会被 Gatekeeper 拦。所有没付费签名的开源 macOS 应用都这样，不是它特有的问题。
  3. 它会申请辅助功能权限。在「隐私与安全性 > 辅助功能」里把 sugarnote 打开。
    打开开关后不用重启 App，它每 2 秒会自己重查一次，菜单栏图标从 ✗ 变 ✓ 就是就绪了。

用法建议

它只在备忘录打开时才有意义。用「快捷指令」的自动化把它和备忘录绑在一起，省得手动开关：

  • 备忘录已打开 → 打开 App → sugarnote
  • 备忘录已关闭 → 退出 App → sugarnote
每条自动化都要把「运行前询问」改成立即运行，否则每次开备忘录都会弹一下问你要不要跑， 那就跟没自动化一样了。

想从源码构建的话，仓库里有完整步骤（SwiftPM，无第三方运行时依赖）。

已知限制

  • 转换在你停手约 150 毫秒后触发。这个去抖是必须的——不然转换会和你的连续输入抢光标位置，把字打乱。
  • 表格、链接、整块 Markdown 转换还没做。
  • 撤销偶尔需要按两次，取决于备忘录自己的编辑分组方式。
  • 只提供 arm64 构建。
